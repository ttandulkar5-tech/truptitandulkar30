# Basics

### 1. What is Python?

**Answer:**
Python is a high-level, interpreted, and general-purpose programming language. It is easy to learn because of its simple syntax and is widely used in web development, automation, data science, AI, and software development.

### 2. What is the difference between a compiled and interpreted language?

**Answer:**
A compiled language converts the entire source code into machine code before execution. An interpreted language executes the code line by line, making debugging easier but generally slower.

### 3. What are variables in Python?

**Answer:**
Variables are names used to store data in memory. In Python, you don't need to declare the data type explicitly because it is dynamically typed.

### 4. What is the difference between a list and a tuple?

**Answer:**
A list is mutable, meaning its elements can be changed after creation. A tuple is immutable, so its elements cannot be modified once created.

### 5. What is a mutable and immutable data type?

**Answer:**
Mutable data types can be modified after creation, such as lists, dictionaries, and sets. Immutable data types cannot be changed, such as strings, tuples, and integers.

### 6. What is the difference between `is` and `==`?

**Answer:**
`==` checks whether two objects have the same value. `is` checks whether two variables refer to the same object in memory.

### 7. What are the data types available in Python?

**Answer:**
Python provides built-in data types such as int, float, complex, bool, str, list, tuple, set, dictionary, and NoneType.

### 8. What does `None` represent in Python?

**Answer:**
`None` represents the absence of a value or a null value. It is commonly used to indicate that a variable has no assigned value.

### 9. What is the difference between a global and local variable?

**Answer:**
A global variable is defined outside a function and can be accessed throughout the program. A local variable is created inside a function and exists only within that function.

### 10. What is the use of `*args` and `**kwargs`?

**Answer:**
`*args` allows a function to accept multiple positional arguments. `**kwargs` allows a function to accept multiple keyword arguments.

# Data Structures

### 11. What is a list in Python?

**Answer:**
A list is an ordered and mutable collection that can store different types of data. Lists allow duplicate values.

### 12. What is a dictionary in Python?

**Answer:**
A dictionary stores data as key-value pairs. Keys must be unique, while values can be duplicated.

### 13. What is a set in Python?

**Answer:**
A set is an unordered collection of unique elements. It automatically removes duplicate values.

### 14. What is list comprehension?

**Answer:**
List comprehension is a concise way to create lists using a single line of code. It makes the code cleaner and more readable.

### 15. What is a nested list?

**Answer:**
A nested list is a list that contains one or more lists as its elements. It is commonly used to represent matrices or multidimensional data.

### 16. What is dictionary comprehension?

**Answer:**
Dictionary comprehension is a short and efficient way to create dictionaries using a single expression.

### 17. What is the difference between `append()` and `extend()`?

**Answer:**
`append()` adds a single element to the end of a list. `extend()` adds all elements from another iterable individually.

### 18. What is the difference between `pop()` and `remove()`?

**Answer:**
`pop()` removes an element by index and returns it. `remove()` deletes the first matching value but does not return it.

### 19. What is the difference between shallow copy and deep copy?

**Answer:**
A shallow copy copies only the outer object, while nested objects are shared. A deep copy creates completely independent copies of all nested objects.

### 20. What is indexing and slicing in Python?

**Answer:**
Indexing is used to access a single element using its position. Slicing is used to access multiple elements by specifying a range.

# Functions

### 21. What is a function in Python?

**Answer:**
A function is a reusable block of code designed to perform a specific task. It improves code readability and reduces repetition.

### 22. What is the difference between a function and a method?

**Answer:**
A function is defined independently, while a method is associated with an object or class and is called using that object.

### 23. What is a lambda function?

**Answer:**
A lambda function is an anonymous function written in a single line using the `lambda` keyword. It is mainly used for short operations.

### 24. What is a recursive function?

**Answer:**
A recursive function is a function that calls itself until a stopping condition is met. It is commonly used for problems like factorial and tree traversal.

### 25. What are default arguments in a function?

**Answer:**
Default arguments provide predefined values to function parameters. If no value is passed during the function call, the default value is used.

### 26. What is the difference between `return` and `print`?

**Answer:**
`print()` displays output on the screen. `return` sends the result back to the caller so it can be used later.

### 27. What is variable scope in Python?

**Answer:**
Variable scope determines where a variable can be accessed. Common scopes are local, global, enclosed, and built-in.

# Strings

### 28. What is a string in Python?

**Answer:**
A string is a sequence of characters enclosed in single, double, or triple quotes. Strings are immutable.

### 29. Why is a string immutable in Python?

**Answer:**
Strings cannot be modified after creation, which improves memory efficiency, security, and performance.

### 30. What is the use of `split()` and `join()`?

**Answer:**
`split()` divides a string into a list based on a separator. `join()` combines elements of a list into a single string.

### 31. What are the different ways of string formatting?

**Answer:**
Python supports string formatting using `%` formatting, `str.format()`, and f-strings. F-strings are the most modern and preferred method.

### 32. What does the `strip()` function do?

**Answer:**
`strip()` removes leading and trailing whitespace or specified characters from a string.

# Object-Oriented Programming (OOP)

### 33. What is a class in Python?

**Answer:**
A class is a blueprint used to create objects. It defines the attributes and methods of an object.

### 34. What is an object in Python?

**Answer:**
An object is an instance of a class. It contains actual values for the attributes defined in the class.

### 35. What is the use of the `__init__` method?

**Answer:**
`__init__` is a constructor that automatically runs when an object is created. It initializes object attributes.

### 36. What is inheritance in Python?

**Answer:**
Inheritance allows one class to acquire the properties and methods of another class. It promotes code reusability.

### 37. What is the use of the `self` keyword?

**Answer:**
`self` refers to the current instance of a class. It is used to access instance variables and methods.

### 38. What is encapsulation?

**Answer:**
Encapsulation is the process of combining data and methods into a single unit and restricting direct access to internal data.

### 39. What is polymorphism?

**Answer:**
Polymorphism allows the same method name to perform different actions depending on the object calling it.

### 40. What is the difference between a class method and a static method?

**Answer:**
A class method works with the class and uses `cls` as its first parameter. A static method does not access instance or class data and behaves like a normal function inside the class.

# Exception Handling

### 41. What is exception handling?

**Answer:**
Exception handling is a mechanism for handling runtime errors without terminating the program unexpectedly.

### 42. What is the use of `try`, `except`, and `finally`?

**Answer:**
`try` contains the risky code, `except` handles errors, and `finally` executes regardless of whether an exception occurs.

### 43. What is a custom exception?

**Answer:**
A custom exception is a user-defined exception created by inheriting from Python's `Exception` class.

---

# Loops & Control Statements

### 44. What is the difference between `for` loop and `while` loop?

**Answer:**
A `for` loop is used when the number of iterations is known. A `while` loop continues until a specified condition becomes false.

### 45. What is the difference between `break`, `continue`, and `pass`?

**Answer:**
`break` exits the loop immediately. `continue` skips the current iteration, while `pass` does nothing and acts as a placeholder.

### 46. What is the `range()` function?

**Answer:**
`range()` generates a sequence of numbers. It is commonly used for controlling iterations in loops.

---

# Modules

### 47. What is a module in Python?

**Answer:**
A module is a Python file containing functions, classes, and variables that can be imported into another program.

### 48. What is the difference between a module and a package?

**Answer:**
A module is a single Python file. A package is a collection of related modules organized in a directory.

### 49. What is the difference between `import` and `from...import`?

**Answer:**
`import` imports the entire module, while `from...import` imports specific functions, classes, or variables from a module.

# Advanced Basics

### 50. What is a generator in Python and what is the use of `yield`?

**Answer:**
A generator is a special function that produces values one at a time instead of storing them all in memory. The `yield` keyword pauses the function and resumes it from the same point when called again, making generators memory-efficient.
